The retired CORE/MEMORY canvas, public log drawer, and journal-first workflow are not part of STRUCTA V3.

## Product journey

1. **TELL** — name the outcome, audience, constraints, and what is already known.
2. **SHOW** — capture a sketch, diagram, space, material, object, or external reference. STRUCTA saves the original before analysis.
3. **KNOW** — inspect the living project map: branches, evidence, constraints, unknowns, risks, decisions, and validation.
4. **NOW** — answer the highest-leverage question or approve one explicit decision. STRUCTA may improve structure and research autonomously, but it never locks a human decision without approval.
5. Review batched visual uncertainties when they materially affect a branch.
6. Export a versioned project corpus that another person or agent can continue without the owner repeating the project.

The home screen remains the four-surface project instrument. Production diagnostics are hidden.

## Fifteen-minute product proof

A first session passes when the user possesses a clear, correctable project map and agrees that NOW is presenting the highest-leverage open decision. The map should require no more than three substantive corrections, and the export should let a collaborator continue without access to the conversation.

## Device release gates

- Correct 240×282 rendering and current build identity.
- Wheel, touch, Side, Back, PTT, camera, and lifecycle events behave once per intentional input.
- Empty voice release creates nothing.
- Originals survive Back, force-close, and offline transitions.
- Visual responses correlate to the exact capture and originating project.
- Silent analysis causes zero speaker output and zero automatic Rabbit Hole entries.
- Decisions remain stable, reversible, and human-approved.
- A sanitized device proof can be exported and validated without credentials, prompts, image data, or transcripts.
